  # Игра «Угадай число» на Go

Консольная игра на языке Go, в которой игроку нужно угадать загаданное компьютером число за ограниченное количество попыток. Проект написан исключительно на стандартной библиотеке Go (`fmt`, `math/rand`, `time`, `os`) без использования сторонних пакетов.

## Возможности

- **Три уровня сложности:**
  - **Easy:** диапазон от `1` до `50`, `15` попыток.
  - **Medium:** диапазон от `1` до `100`, `10` попыток.
  - **Hard:** диапазон от `1` до `200`, `5` попыток.
- **Подсказки по направлению и расстоянию:**
  - Указание больше или меньше загаданное число (`Секретное число больше 👆` / `Секретное число меньше 👇`).
  - Оценка близости к ответу: `🔥 Горячо` (разница ≤ 5), `🙂 Тепло` (разница ≤ 15), `❄️ Холодно` (разница > 15).
- **История попыток:** вывод списка всех ранее введённых чисел в текущем раунде.
- **Защита от некорректного ввода:** обработка текста, пустых строк и чисел вне диапазона без потери попытки.
- **Цветной интерфейс в терминале:** выделение заголовка, победных сообщений (зелёный), поражений и ошибок (красный), а также счётчика попыток (жёлтый) через ANSI-коды.
- **Сохранение статистики:** автоматическая запись результатов всех сыгранных раундов в файл `results.json` между запусками программы.

## Требования

- Установленный **Go** (версии 1.27.1 или выше).

## Как запустить

1. Склонируйте репозиторий или перейдите в директорию с проектом:
   ```bash
   cd golang-me
   ```

2. Запустите игру командой:
   ```bash
   go run main.go
   ```

## Структура проекта

- `main.go` — основной исходный код игры.
- `go.mod` — файл инициализации модуля Go.
- `results.json` — файл с историей результатов игр (создаётся автоматически после завершения первого раунда).
- `README.md` — документация проекта.
