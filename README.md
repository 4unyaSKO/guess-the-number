# Игра «Угадай число» на Go

Консольная игра на языке Go, в которой игроку необходимо угадать загаданное компьютером число за ограниченное количество попыток. Проект написан с использованием только базовых пакетов стандартной библиотеки (`fmt`, `math/rand`, `time`).

## Возможности

- **Три уровня сложности:**
  - **Easy:** диапазон от `1` до `50`, `15` попыток.
  - **Medium:** диапазон от `1` до `100`, `10` попыток.
  - **Hard:** диапазон от `1` до `200`, `5` попыток.
- **Умные подсказки:** после каждой попытки игра указывает направление («больше» / «меньше») и степень близости к ответу (`🔥 Горячо`, `🙂 Тепло`, `❄️ Холодно`).
- **История ходов:** отображение списка всех ранее введённых чисел в текущем раунде.
- **Валидация ввода:** защита от некорректного ввода (букв, символов или чисел вне диапазона) без потери попытки.
- **Цветной интерфейс:** выделение статусов, подсказок и результатов в терминале с помощью ANSI-кодов.
- **Повторная игра и статистика:** возможность сыграть несколько раундов подряд с выводом итоговой истории игр в формате JSON.

## Требования

- Установленный компилятор **Go** (версии 1.18 или выше).

## Как запустить

1. Склонируйте репозиторий или перейдите в папку с проектом:
   ```bash
   cd guess-the-number
   ```

2. Запустите программу командой:
   ```bash
   go run main.go
   ```
